# SAM 생윤·윤사 법적 고지

`SAM 생윤·윤사`의 공개 법적 고지 페이지입니다.

- [법적 고지 홈](https://faithforone.github.io/sam-ethics-legal/)
- [서비스 이용약관](https://faithforone.github.io/sam-ethics-legal/terms/)
- [개인정보처리방침](https://faithforone.github.io/sam-ethics-legal/privacy/)
- [실제 서비스](https://sam-ethics.vercel.app/)

시행일은 2026년 8월 30일입니다. 이 저장소에는 정적 HTML 문서만 두며 서비스 소스코드, 비밀키, 운영자 인증정보를 포함하지 않습니다.

개인정보처리방침은 처리 현황을 공개하는 문서이며 동의서가 아닙니다. 현재 별도 선택 동의가 필요한 핵심 처리는 카카오가 제공하는 이메일·프로필 닉네임·프로필 이미지와, AI 주관식 최초 이용 시의 DeepSeek 국외이전입니다.

## 문서에 반영한 실제 데이터 흐름

- 카카오 로그인은 카카오 회원번호만 필수로 사용합니다. Supabase 기본 Kakao OAuth가 이메일, 프로필 닉네임, 프로필 이미지를 선택 동의로 요청할 수 있고, 이용자가 허용한 값은 Supabase Auth 메타데이터에 저장될 수 있습니다. 이메일은 Supabase의 동일 검증 이메일 인증 자동 연결에 사용될 수 있지만 앱의 랭킹·학습 기능에는 사용하지 않습니다.
- 학생 아이디 로그인은 아이디, Supabase Auth가 처리하는 비밀번호, 내부 인증용 주소, 약관 버전·시각, 만 14세 이상 확인과 별도 랭킹 닉네임을 처리합니다.
- 기존 토스 회원은 `userKey`, 선택 제공 이메일의 SHA-256 해시, 로그인·연결 해제 이력으로 계정을 유지합니다. 회원 매핑 데이터베이스에는 이메일 원문을 저장하지 않습니다.
- Supabase 프로젝트의 주 데이터베이스는 AWS 서울 `ap-northeast-2`, Vercel 기본 실행 지역은 서울 `icn1`입니다. 해외 본사·지원 인프라의 원격 처리 가능성은 국외이전 항목에 함께 공개합니다.
- Vercel Web Analytics는 제3자 쿠키 없이 익명화된 집계 통계를 생성하며, 런타임 로그 보유기간은 적용 요금제에 따라 달라집니다.
- DeepSeek에는 무작위 식별자, 질문·채점 기준과 짧은 답안만 전송하며 직접 식별자는 요청 본문에서 제외합니다.
- 신규·기존 회원 모두 첫 AI 주관식 이용 때 계정별로 한 번 국외이전 선택 동의를 받습니다. 서버 관리 `app_metadata`에 동의 문안 버전과 시각을 기록하고 이후 재사용합니다. 거부 또는 철회 시 답안을 전송하지 않고 “모르겠어요”로 진행합니다.
- 만 14세 이상 18세 미만 회원은 DeepSeek 이용 조건에 따라 법정대리인과 관련 약관·국외이전 안내를 함께 읽고 법정대리인의 동의를 얻은 경우에만 AI 기능을 선택합니다.
- AI 판정은 내부 학습 피드백·진도·XP·랭킹에만 영향을 주며 공식 성적, 입시, 자격, 결제 또는 회원 자격을 결정하지 않습니다. 불확실하거나 신뢰도 0.85 미만인 결과는 오답으로 확정하지 않고 사람의 설명·재검토 요청 경로를 둡니다.
- 회원 기능은 만 14세 이상만 이용할 수 있습니다. 현재 베타는 무료이며 결제 기록 보존 조항은 향후 유료 서비스가 시작될 때 적용됩니다.

## 운영 점검표

- [ ] 카카오 개발자 콘솔의 `account_email`, `profile_nickname`, `profile_image`가 모두 “선택 동의”이고 거부해도 회원번호로 정상 가입·로그인되는지 정기 검증
- [ ] 카카오 선택정보를 앱 기능에서 사용하지 않는 현재 구조가 바뀌면 목적·법적 근거·보유기간과 동의 화면을 함께 개정
- [ ] 만 14세 이상 확인을 가입 UI와 서버 모두에서 검증하고, 미성년 오가입 신고 시 계정 제한·삭제 절차를 실행
- [ ] 14~17세의 AI 최초 이용 화면에서 법정대리인과 DeepSeek 약관·국외이전 안내를 확인하고 동의를 얻었다는 절차를 제공하거나, AI를 거부하고 “모르겠어요”를 선택하게 하기
- [ ] DeepSeek 동의 버전·시각이 서버 관리 메타데이터에만 기록되고 클라이언트가 위조할 수 없는지 검증
- [ ] 동의하지 않은 계정과 철회한 계정의 주관식 답안이 DeepSeek로 전혀 전송되지 않는지 회귀 테스트
- [ ] DeepSeek 전송 본문에 이름, 닉네임, 카카오 회원번호, 학생 아이디, 이메일, Supabase 회원번호, 학교·반, 연락처가 포함되지 않는지 로그·코드 점검
- [ ] DeepSeek의 법인명, 처리 국가, API 보유·문맥 캐시·학습 이용 정책과 하위처리자가 바뀌면 동의 문안을 갱신하고 중대한 변경은 재동의
- [ ] DeepSeek Open Platform이 다운스트림 입력의 고정 보유기간과 모델 학습 미이용을 공개적으로 보장하지 않는 공백을 출시 전 계약·지원 답변으로 확인하고, 확인되지 않으면 고정보유·학습 미이용을 보장하는 대체 모델 사업자 검토
- [ ] AI 결과 설명·사람의 재검토·학습 기록 정정 요청을 고객센터에서 접수하고 처리 이력을 남길 수 있는 운영 절차 마련
- [ ] Supabase 주 리전, DPA, 재위탁자, 요금제별 최대 30일의 백업 보유·교체 주기와 계정 삭제 후 실제 파기 시점을 확인
- [ ] Vercel 실행 리전, DPA, Web Analytics 설정과 현재 요금제의 런타임 로그 보유기간을 확인하고 문서의 요금제별 안내와 일치시키기
- [ ] 회원 탈퇴가 Supabase Auth, 계정 연결, 학습·랭킹·초대 데이터까지 삭제하도록 운영하고 카카오·토스 “연결 해제”와 차이를 안내
- [ ] 랭킹 닉네임 변경·제외, 카카오 선택정보 삭제, AI 국외이전 동의 철회 요청을 고객센터에서 처리할 수 있도록 요청 양식과 내부 기록 마련
- [ ] 초대 토큰, 문의, 보안 로그, 동의 증빙, 백업의 보유기간을 실제 자동 삭제 작업과 일치시키기
- [ ] 수탁자·국외이전·수집 항목·기능·보유기간이 바뀌면 배포 전에 이용약관, 개인정보처리방침, 동의 화면, 변경 이력을 함께 갱신
- [ ] 유료 상품을 출시하기 전에 가격, 기간, 이용범위, 자동 갱신, 청약철회·환불 안내와 통신판매업 신고·면제 여부를 별도 검토
