## 출시 전 점검

- 실제 Toss Login 동의 범위와 서비스에서 처리하는 회원 식별정보를 최종 확인합니다.
- 운영 데이터베이스·호스팅의 실제 처리 구조와 국외 이전 여부를 확인하고 필요한 경우 개인정보처리방침을 갱신합니다.
- 유료 상품을 출시할 때 과목, 가격, 이용기간, 이용범위 및 환불 조건을 구매 화면에 명확히 표시합니다.
- 통신판매업 관련 신고·면제 여부를 거래 개시 전에 다시 검토합니다.
